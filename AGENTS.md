# Agent Entry

Use the installed ETHOS product: run `ethos status --root . --json` and follow
its current result. Read the reported `agent_guidance.path` for version-matched
operation guidance. OpenSpec owns accepted Change intent; this file grants no
mutation authority.

Start at [README.md](README.md) for source ownership and
[CONTRIBUTING.md](CONTRIBUTING.md) for the editing journey. The selected official
Change's `tasks.md` is the only implementation checklist; documentation and
memory must not create another progress authority.

Manuscript meaning and reader references belong in `book/`; edition identity
belongs in `book/metadata.typ`; presentation belongs in `publication/layout/`,
diagnostics in `publication/diagnostics/`, supply manifests in
`publication/supply/`, and third-party notices in `publication/rights/`.
The native task interface remains `publication/justfile`; editable figures
belong in `diagrams/`; synthetic teaching
inputs belong in `exercises/cases/`, grouped with each case’s code and expected
outcome; reusable cards belong in `exercises/templates/`, and transfer cases
belong in `exercises/assessment/`. Keep generated artifacts under ignored `build/`.
Do not copy machine inventories, credential stores or raw conversations into
portable source.

Use the declared tasks, not a new installer or publication controller. Preserve
the pinned publisher package without vendor edits. Compilation, semantic checks,
every-page visual self-review, human acceptance and publication are distinct.
Carry case dates and unresolved limitations through any prose revision.

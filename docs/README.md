# Contributor guides

These guides explain how to maintain and qualify the publication. Reader-facing
teaching belongs in [book](../book/README.md), not in a second manual here.

- [Editing and build journey](contributing.md): select the right source owner,
  make a governed change and rebuild its consumers.
- [Edition acceptance](publication-acceptance.md): distinguish source tests,
  complete-content checks, visual review and reader delivery.

The active Change owns progress. These procedures do not record a candidate as
accepted and do not authorize remote publication.

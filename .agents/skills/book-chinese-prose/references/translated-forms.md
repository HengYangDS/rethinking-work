# Translated forms that keep coming back

Each entry: the form, why it reads as translated, and the written-Chinese form that replaces it. Examples are from
the book before 2026-11-26. Judge by sense; a form that is right in its place stays.

## English verbs carried over word for word

| 原文                               | 改为                                       | 为什么                            |
| ---------------------------------- | ------------------------------------------ | --------------------------------- |
| 怎样读出一个人这一期的表现         | 怎样从一个人做过的事里，看出他这一期的表现 | read off 直译，中文说“看出”“判断” |
| 任何一人读出 S                     | 只要有一人评为 S                           | 同上                              |
| 各自先写                           | 独立评定                                   | write independently 直译          |
| 回到证据求同                       | 对照证据统一意见；一起重新核对证据         | go back to the evidence 直译      |
| 由有权决定的人带进以它为依据的决定 | 由决策负责人用于……的决定                   | carry into 直译                   |
| 说出了自己的工作最可能错在哪里     | 指出了工作中最可能出错的地方               | 口语加英文语序                    |

## English participles and clauses as modifiers

| 原文                             | 改为                             |
| -------------------------------- | -------------------------------- |
| 显出的能力、可担的责任           | 能力要求、职责范围               |
| 这一期分派的工作涉及的每一项要求 | 本期所派工作涉及的每一项要求     |

## Passive voice where Chinese is active

| 原文                         | 改为                                                     |
| ---------------------------- | -------------------------------------------------------- |
| 至少有一件被验收并使用的结果 | 至少有一项成果通过验收并投入使用                         |
| 这一次的结论也被别人直接用过 | 这一次的结论也被他人直接采用；他人直接采用了这一次的结论 |

## A circumlocution where the book has a name

「有权决定的人」 → 「决策负责人」 (chapter 23 fixes the five role names for the whole book). A paraphrase of a fixed
name makes the reader wonder whether a different person is meant.

## Rule cascades written like code

Long chains of 「……的，……；……的，……；否则……」 that walk every branch of a rule read as a specification, not as a
book. State the principle and its reason in one or two sentences, the main rule after, and leave edge cases to the
place that needs them or to the department guidelines. Counting rules (which period a result falls in, when a
count starts again) are said once, plainly.

## Demonstrative chains and noun stacks

「的那一件」「的那一项」「它所依据的那份记录」 strung through a paragraph: name the thing. 「对……的……的……」 stacks:
break the sentence, put the actor first.

## Register

- Spoken shortcuts in place of written words: 担起 → 承担；照用 → 沿用；弄明白 (outside the chapters that argue with
  it) → 理解、查明；读得出 → 看得出、判断得出.
- Officialese is not the remedy: 「予以」「进行+动词」「对……加以」 are as foreign as calques.
- 「宜」 as a rule's modal: once in a while is fine; three in a page reads like a standard, not a book. Prefer 「应当」
  for a rule and plain description for a practice.

## Calibration cases: forms rejected

「盲处」 (→ 盲点), 「通篇顺滑，没有毛刺」 (engineering image), 「收不回来的事，一步也不省」 (spoken shortcut): each passed
a model reader because its meaning was recoverable. Test a phrase against "would a careful Chinese editor print this
in a book", not against whether its meaning can be guessed.

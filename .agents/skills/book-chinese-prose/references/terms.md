# Names the book has fixed

One concept, one name, throughout the book. The Vale style `book` holds the decidable replacements
(`.config/checks/vale/styles/book/decided-terms.yml`, `avoided-words.yml`); this table holds the names themselves.

## Roles (`book/parts/roles.typ`)

| 名称       | 指什么                                                                                                       | 不写成                           |
| ---------- | ------------------------------------------------------------------------------------------------------------ | -------------------------------- |
| 任务负责人 | 说清目标和边界、统筹安排、对结果从头负责的人                                                                 | 主责的人、牵头人                 |
| 执行人     | 拆解、委托、实现、整合、核验的人                                                                             | 干活的人                         |
| 评审人     | 独立核查事实、改动和证据的人                                                                                 | 审的人                           |
| 验收人     | 在获得授权的前提下决定结果能否交付使用的人                                                                   | 收活的人                         |
| 决策负责人 | 裁定值不值得做、无法撤回的那一步是否执行的人；评定和晋升由部门负责人或他授权的组长决定，这个人就是决策负责人 | 有权决定的人、有权的人、拍板的人 |

## Evaluation (`book/parts/talent.typ`, after the department guidelines)

| 名称               | 指什么                                                           | 不写成                   |
| ------------------ | ---------------------------------------------------------------- | ------------------------ |
| 评分               | 对一件工作的打分，五级                                           | 分（单用作名词）、打的分 |
| 评定等级           | 一个人在一个评定周期内、对照本职级要求的表现，S、A、B、C、D 五档 | 字母、档位（指人时）     |
| 评定周期           | 两次评定之间的一段时间                                           | 一期（首次出现须先说明） |
| 职级               | 专业序列上的位置，器、术、法、道四段八级                         | 级别、等级               |
| 能力要求、职责范围 | 职级表的两栏                                                     | 显出的能力、可担的责任   |
| 通过验收并投入使用 | 成果验收合格并实际使用                                           | 被验收并使用             |
| 带教人             | 负责指导成员的人                                                 | 带教                     |
| 改进计划           | 为达到某几项要求而书面约定的目标、支持和期限                     | 改进期（单独使用时）     |

## Everyday working words

| 写                       | 不写             |
| ------------------------ | ---------------- |
| 由没参与修改的人逐句通读 | 冷读             |
| 下载回来核对             | 读回             |
| 合入                     | 落地（指提交）   |
| 完整验证                 | 证明（指 proof） |

## Words used across chapters

A word the book uses in one sense across chapters, such as 最可能错在哪里 or 询问人, is changed everywhere or nowhere: the
editor decides for the whole book, because changing one place would split the term.

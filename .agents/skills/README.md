# Repository Skills

Skills here guide agents that work on this repository; they route to the repository's own sources and add the
practice those sources leave open. `activation.toml` routes each one; it holds no authority over the book, the
tests, OpenSpec or evidence. Host directories such as `.claude/skills/` are projections, not sources.

- `book-chinese-prose`: writing, editing and reading the book's Chinese. Load it before editing `book/`.
- `book-delivery`: committing, reviewing, archiving, proving, landing, publishing and retiring a lane here. Load it
  before the first commit of a Change.

The Skill in `exercises/cases/export-regression/agent/` is reader material that the book teaches readers to install;
it is not a Skill for agents working here.

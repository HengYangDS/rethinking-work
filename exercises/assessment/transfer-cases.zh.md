# 迁移题

三道题各取书中一个练习或一节，换一个条件再问一次。先写下自己的答案，再读后面的要点。

## 题目

### 一、重复的两行不再相同

承接练习“复原当时知道什么”，数据在 `cases/historical-snapshot/`。原件中，S03 的第二版重复记录了两行（第 6、7 行），内容相同。在副本中把第 7 行的收益改为 65，第 6 行仍是 60。

1. 冻结时刻 S03 的值，`reconcile.sql` 给出多少？它的输出把这处差异归给谁？
2. 把第 6、7 两行的收益对调，输出又会怎样？
3. S03 的结论应当怎样写？

### 二、收益从 CSV 文件读入

承接练习“核验一处改动”，代码在 `cases/export-regression/`。上游改为用 Python 的 `csv` 模块直接读一份 CSV 文件，每个值都读成字符串：零读成 `'0'`，空的单元格读成 `''`。文件有四行，S01 至 S04 的收益依次是 0、50、−100 和空。

1. 修改前和修改后的两个版本，各导出哪几只？
2. 修改后的版本还能通过 `test_export.py` 吗？这说明什么？
3. 应当改在哪里？

### 三、三处用的不是同一个版本

承接“工具：它能操作什么”一章“安装之后，智能体未必看得见”一节。一个检索工具升级到新版，新增了一个按日期过滤的参数。在命令行里用这个参数，结果正确；在一个 Claude Code 会话里，智能体通过 MCP 服务调用这个工具时，提示没有这个参数；团队的网页上也提供同样的检索，那里没有这个选项。

1. 问题可能出在哪几处？各怎样查？
2. 能否就此说“已经升级好了”？
3. 网页由别人维护，自己能做的是哪一步？

## 要点

### 一

1. 65。S03 在冻结时刻可用的这两行，版本、公布时间和入库时间都相同，查询按行号取了后一行。输出把 S03 列为 `value_mismatch`，快照减预期为 −5，看上去是快照错了。
2. 对调之后取到的是 60，与快照一致，S03 从输出中消失。同样的数据，行序一换，结论就变：这个值是排序随手定的，不是数据定的。`quality.sql` 两次都不报告这一点。
3. 同一版本的两行数值不同，是来源自相矛盾，不是可以按顺序任取一行的重复。取最新版本之前，先检查同一版本的各行是否一致：一致，才按约定取一行；不一致，就把 S03 记为来源冲突，不给值，去问来源。这与练习“总数一样，谁是谁不一样”中匹配到两个主体时不任选一个，道理相同。

### 二

1. 修改前导出 S01、S02、S03：`'0'` 是非空字符串，判为真，碰巧保留了下来；`''` 判为假，被去掉。修改后四只都导出，S04 的收益是空字符串，一个未知的值被当作有值导出。
2. 能通过。测试用的是整数 0 和 `None`，没有字符串形式的数据，这次的错误它查不出来。修改前的版本这次碰巧对了，也不说明它原本正确。
3. 先改约定：写明读入的数据中，零和未知各是什么样子；在读入的地方把 `''` 转为 `None`，把数字转为整数，函数中“去掉空值、保留零”的规则不变。再给测试加上字符串形式的数据，用现在的版本让它先失败一次，然后修改。

### 三

1. 三处各有各的版本。命令行用的是刚装上的新版。会话中的工具清单是会话开始时取得的：会话若在升级之前就已开始，清单还是旧的；也可能这个宿主接入的不是刚升级的那一份。网页部署的是另一份，与本机的安装无关。查法：在出问题的那个宿主中另起一个会话再试；用 `claude mcp list` 看这个宿主接入了哪些服务、能否连上，再查它的配置启动的是哪一份程序、是什么版本；网页则看它部署的版本。
2. 不能。命令行中成功，只说明命令行这一处是新版；哪一处要用新参数，就在哪一处检验。也不必把程序和宿主全部重装，从出问题的那一处查起。
3. 自己机器上宿主的接入，可以自己改；网页的部署，交给维护它的人，写明版本、用法和看到的现象。

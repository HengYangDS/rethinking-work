## Context

See [proposal.md](proposal.md). The verification jobs are generated by ETHOS from `.config/ci/verification.toml`; the
publication jobs come from `.config/ci/pipeline.cue`, which already reads the GitHub runner from that file.

## Goals / Non-Goals

**Goals:**

- One declaration of each forge's macOS runner label, read by every job of that forge.

**Non-Goals:**

- Removing Windows from the Mise lock and the specification (a lane of its own after 0.2.6).

## Decisions

- GitLab tags are `macos-latest` with `review` or `protected`, mirroring GitHub's `macos-latest` and the guidelines
  repository. The runners get the new tags first and keep the old until `main` is published, so no job waits for a
  runner.

## Risks / Trade-offs

- `macos-latest` moves with GitHub's hosted images; the owner chose it over a fixed label.
